# 首页风格探索记录

> 本记录用于本次首页视觉作业。14 种已有风格的判断依据是项目现有主题说明与 CSS 设计规则；探索页均使用相同的首页文案、功能、步骤和页脚状态。

## 现有 14 种风格：一句话判断

- **温馨插画风：** 适合家庭照护主题，奶油底和圆润插画亲切，但照片更能呈现真实家庭记忆。
- **扁平：** 可读、直接，适合功能介绍，但情感和相册感不足。
- **拟物：** 记录本隐喻贴题，不过重纹理容易分散注意力。
- **Material Design 3：** 组件层级明确，作为通用管理页稳妥，但品牌辨识度偏低。
- **新拟态：** 柔软效果温和，但低对比会影响按钮和文字辨认。
- **毛玻璃：** 图片叠层很有氛围，但正文对比和长时间阅读不够稳定。
- **黏土风：** 造型可爱，适合轻松表达，但大量立体卡片会显得幼稚。
- **新野兽派：** 个性鲜明，但高对比硬阴影和撞色不符合温柔记录的气质。
- **便当盒布局：** 功能分区清楚，适合管理信息，但落地页需要更强的故事感。
- **瑞士风格：** 栅格和层级清楚，阅读效率高，不过情绪较理性。
- **杂志编辑风：** 大标题和留白有质感，适合讲述故事，但记录入口可能不够突出。
- **孟菲斯：** 活泼醒目，但装饰密集容易和照护信息争抢注意力。
- **深色模式：** 夜间阅读舒服，但猫咪照片和家庭温度会被压暗。
- **极简：** 干净克制，但如果装饰和层级过少，页面容易显得空。

## 候选风格（最终比较的三种）

- **手账：** 点阵纸、荧光笔标题和打勾步骤能把体重、疫苗等日常记录整理得清楚，也有亲手照顾猫咪的感觉；装饰需要克制，才不会影响阅读。
- **宠物病历本：** 夹板和表单很适合呈现体重、疫苗及就诊信息，让健康记录一目了然；颜色和批注可以柔和一些，避免整页看起来像医院。
- **日系杂货：** 自然的米白、木色和留白让页面安静耐看，也适合长期查看猫咪档案；需要用照片或少量重点色增加记忆点。

手账替换了之前的家庭相册候选。最终从这三种中选定 Japanese Minimalist（日系极简），并已应用到首页。

## 最终选择

**风格：Japanese Minimalist（日系极简 / 日系杂货）。** 这个风格留白充足、分隔清楚，适合经常查看猫咪健康与日常记录；自然的照片和材质也能保留温暖感，不会像病历本那样太像医疗工具。

**主色调：** 背景浅蓝灰 `#F2F5F8`；主色靛蓝 `#2B4C6F`；正文深灰 `#2C363F`；点缀蓝灰 `#5B82A6` 和鼠尾草绿 `#7A9A8B`；分隔线 `#D3DEEA`。浅蓝灰与靛蓝让页面沉静、清晰，蓝灰和鼠尾草绿只用于少量强调。
